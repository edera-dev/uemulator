New machine

How the machine starts. No network in the browser; the console is the terminal behind this panel.

Firmware image

A UEMUFW64 image (from crates/uemulator-firmware) is booted as UEFI; anything else is placed below 1 MiB and started at F000:FFF0. OVMF and other EDK2 builds are not supported.

Initramfs (optional)
Disk (optional)

Attached as vda. Raw or udisk, read on demand and never downloaded whole; the guest's writes stay in memory and are gone when it stops. A URL must be served with range requests. Overlays must be flattened first (uemulator disk convert).
